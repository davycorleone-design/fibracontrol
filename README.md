# FibraControl — versão 6

Esta versão atualiza o símbolo da marca para o desenho escolhido, com gradiente azul/ciano mais suave e fundo transparente incorporado no HTML.

## Publicar no GitHub Pages
1. Abra o repositório `fibracontrol`.
2. Envie o arquivo `index.html` desta pasta para substituir o arquivo atual.
3. Confirme em **Commit changes**.

O símbolo está incorporado no HTML; não é necessário enviar uma imagem separada. A publicação no GitHub não é feita automaticamente por este pacote.
